BDD :

Tables

- users => contient tous les utilisateurs qui ont accès au site
- users_cours => les inscriptions des users aux différents cours
- cours => Les cours disponible sur le site
- modules => les modules proposés dans les cours
- videos => les vidéos dispo dans les modules, cette table contiendrait également les scripts textuels des vidéos. 
            Idéal si y'a besoin de réutiliser une vidéo dans plusieurs modules
